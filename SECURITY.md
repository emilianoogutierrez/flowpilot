# Reporting a security issue

Do not post secrets, customer input or exploit details in a public issue. Contact emiliano.sinlib@gmail.com with the affected version, a description of the boundary involved and a minimal local reproduction.

There is no paid support agreement or guaranteed response time. Only supported releases from this repository are in scope.

The [security model](docs/security.md) and [verification report](verification/REPORT.md) distinguish implemented controls from unverified deployment properties. Passing tests is not a security certification.
